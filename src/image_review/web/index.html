Who is reviewing?

Your name (1-64 characters) is recorded with every verdict.

Enter accepts; Escape keeps the current name.

Keys

c
Mark the image (or every image in the grid) CLEAN
d
Mark it DIRTY
← →
Previous / next item, without marking
z
Undo this page's latest mark and show it again
m
Grid mode for the current batch (images may be rotated)
M
Grid mode without rotation
s
Single mode (rereads the list)
b
Grid mode: the next batch with images to review
r
Reconnect, when its button is shown: after a lost connection, after q, or at the end of a pass
q
Done with this server: nothing more is sent; the page waits for the next serve
? h
This help (Escape closes it)

The bar's colour is the item's status, also written in it: grey UNREVIEWED, green CLEAN, red DIRTY, amber FLAGGED (grey too on the end screen and while stopped). A scale badge such as “⚠ 46%” means the image is shrunk to fit: small burned-in text can be lost, so enlarge the window.

A verdict counts only once the item has been on screen for a moment; closing this help starts that wait again.

When the pass is done the page says so: stop serve (Ctrl-C), start the next one, then press Reconnect (r). To move on to the next serve earlier (another batch), press q first. Your marks are saved as you make them.
